### 4. บริการเปิดให้เช่าร้านจัดแข่งอีสปอร์ต (Esports Tournament Venue Rental)
ทางร้านมีเวทีแข่งขัน **5v5 Tournament Stage** มาตรฐานสากล พร้อมจอ LED Wall ขนาดยักษ์, ระบบ Live Streaming Broadcast และโต๊ะพากย์ Caster Desk ครบวงจร

**เงื่อนไขและข้อมูลที่ต้องใช้ในการขอเช่าจัดแข่ง (6 ข้อสำคัญ):**
1. วันและเวลาที่ต้องการจัดงาน (เริ่ม - สิ้นสุด)
2. เกมที่ใช้แข่งขัน (เช่น VALORANT, ROV, PUBG, CS2, FC24, Street Fighter 6)
3. ชื่องาน / กิจกรรม
4. ชื่อบริษัท / องค์กร / ผู้จัด / สถาบัน
5. จำนวนคนและทีมโดยประมาณ (ผู้เล่น + ผู้ชม)
6. ข้อมูลติดต่อกลับ (ชื่อผู้ประสานงาน, เบอร์โทรศัพท์, LINE ID / อีเมล)

### 5. ข้อมูลการลงทุนแฟรนไชส์และงบประมาณเปิดร้าน (Franchise & Turnkey Investment)
G-Speed มีโมเดลการลงทุนให้เลือก 3 ขนาด:
1. **Size S (30-40 เครื่อง):** งบประมาณ 1.8 - 2.5 ล้านบาท (เหมาะกับอาคารพาณิชย์ 2 คูหา คืนทุนเฉลี่ย 14-18 เดือน)
2. **Size M (50-70 เครื่อง):** งบประมาณ 3.2 - 4.5 ล้านบาท (โมเดลยอดนิยม คืนทุนเฉลี่ย 18-24 เดือน)
3. **Size L Mega Arena (80-120 เครื่อง):** งบประมาณ 5.5 - 8.0 ล้านบาท (พร้อมเวทีแข่ง 5v5 และห้อง VIP)

**สิ่งที่รวมในแพ็กเกจ Turnkey:**
- คอมพิวเตอร์สเปกแข่งขันครบชุด + จอ 360Hz/240Hz
- ระบบ Diskless Server NVMe ไม่ต้องมี HDD เครื่องลูก
- ระบบ Network 10Gbps Multi-WAN รวมเน็ต 2-3 ค่าย Ping ต่ำ < 3ms
- ระบบคิดเงิน POS บัญชีคลาวด์ สต็อกสินค้า
- ออกแบบผังร้าน 2D/3D และแบรนดิ้งตามมาตรฐาน G-Speed
- อบรมบุคลากรและทีมวิศวกรดูแลระบบตลอดอายุสัญญา

*ปรึกษาคำนวณงบประมาณและสำรวจหน้างานฟรี โทร 063 793 7704*

### 6. บริการรับติดตั้งและวางระบบร้านเกมครบวงจร (Cyber Cafe Solutions)
- **ระบบ Diskless Server:** รองรับ CCBoot และ iCafeCloud บูตเครื่องเข้า Windows ใน 12 วินาที อัปเดตเกมจุดเดียว มี Auto-Failover สำรอง
- **ระบบเน็ตเวิร์ก 10Gbps Multi-WAN:** เดินสาย CAT6A / Fiber Optic แกนหลัก 10Gbps แยก VLAN ไม่แล็ก ค่า Ping < 3ms
- **ระบบไฟฟ้า 3 เฟส:** บาลานซ์โหลด ตู้โหลดเซ็นเตอร์ ระบบกราวด์สายดินปลอดภัย 100% พร้อม UPS True Online
