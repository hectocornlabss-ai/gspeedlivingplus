## 1. ภาพรวมสถาปัตยกรรมระบบรวมแชท (Unified Omnichannel Hub)

ลูกค้าของ G-Speed สามารถทักเข้ามาได้จาก **3 ช่องทางหลัก**:
1. **LINE Official Account (@gspeedarena)** (คนไทยนิยมสูงสุด)
2. **Facebook Page Messenger** (งานแข่ง, สอบถามโปรโมชัน)
3. **Web Chat Widget** (ลูกค้าบนหน้าเว็บไซต์ที่กำลังดูผังร้าน 3D หรือหาพิกัดร้าน)

ข้อความทั้งหมดจะถูกส่งเข้าสู่ **ศูนย์กลางเดียวกัน (Unified Inbox)** โดยมีระบบ **AI ตอบด่านหน้า** และ **แอดมินคนจริงสามารถเข้ามาตอบแทรกได้ทันที พร้อมระบุชื่อแอดมินอย่างชัดเจน**:

```
 [ LINE OA ]      [ Facebook Page ]     [ Web Chat Widget ]
      │                   │                     │
      └───────────────────┼─────────────────────┘
                          │ (Webhook)
                          ▼
            ╔═════════════════════════════╗
            ║     ★ CHATWOOT INBOX ★      ║
            ║    (หน้าจอรวมแชทศูนย์กลาง)    ║
            ╚═════════════════════════════╝
                          │
        ┌─────────────────┴─────────────────┐
        ▼                                   ▼
 [ 🤖 AI AUTO-REPLY ]             [ 👤 HUMAN AGENT TAKEOVER ]
 • Gemini Flash 3.8               • แอดมินกด "รับเคส" (Assign)
 • RAG ข้อมูลร้าน 24 ชม.          • AI จะ Mute หยุดตอบทันที
 • ตอบทันทีใน 1-2 วินาที          • ระบุชื่อแอดมินที่ตอบชัดเจน
                                  • บันทึก Log ประวัติแอดมิน
```

## 2. กลไก AI First + Human Takeover (แอดมินตอบแทรก & บันทึกชื่อคนตอบ)

### ทำไมต้องใช้ Chatwoot เป็นตัวรวมแชท?
- **Chatwoot** คือระบบ Open-source Customer Engagement Platform ระดับโลก (เทียบเท่า Zendesk แต่รันฟรีบน Docker ตัวเองได้)
- รองรับการเชื่อมต่อ LINE, Facebook, และ Web Widget ในหน้าจอเดียว
- มี **Agent Identification**: ทุกข้อความที่แอดมินพิมพ์ตอบ จะประทับชื่อและรูปโปรไฟล์แอดมินคนนั้น (เช่น *“แอดมิน กอล์ฟ (ฝ่ายบริการ)”*) ทำให้ลูกค้ารู้สึกอุ่นใจ และผู้บริหารสามารถตรวจสอบย้อนหลังได้ว่าใครเป็นคนตอบ

### ลำดับขั้นตอนการทำงาน (Human Handover Protocol):
1. **เมื่อลูกค้าทักเข้ามา (Status: `Pending / Bot`)**:
   - Chatwoot ส่ง Event Webhook ไปหา **n8n**
   - n8n เรียก **Gemini Flash 3.8 + External RAG** ตอบข้อมูลร้านทันที (เปิด 24 ชม., พิกัดร้าน, ราคา, สเปกคอม)
2. **เมื่อแอดมินต้องการตอบแทรก (Status เปลี่ยนเป็น `Open / Assigned`)**:
   - เมื่อแอดมินเห็นแชทในหน้าจอ Chatwoot แล้วกดคลิก **"Assign to Me"** หรือเริ่มพิมพ์ข้อความแรก
   - Chatwoot จะส่ง Event `conversation_assigned` หรือ `message_created (by agent)` ไปหา n8n
   - n8n จะ **Pause / Mute AI ทันทีเป็นเวลา 60 นาที** ทำให้ AI หยุดตอบในห้องแชทนั้น ไม่ตอบชนกับแอดมินเด็ดขาด
3. **การส่งต่อแชทข้ามแผนก (Department Re-assignment)**:
   - หากลูกค้าคุยเรื่องการเงิน/จัดแข่ง แอดมินสามารถกดส่งต่อห้องแชท (Transfer) ไปยังทีมจัดแข่งหรือฝ่ายขายแฟรนไชส์ได้ในคลิกเดียว

## 3. ระบบสรุปรายรับ / รายจ่ายรายวัน (Daily Cashflow & P&L Automation)

ระบบจะสรุปบัญชีการเงินประจำวันอัตโนมัติ โดย n8n เชื่อมต่อกับ **SmartCafé POS** และระบบบัญชี:

```
 [ SmartCafé POS หน้าร้าน ]         [ บันทึกรายจ่ายสดย่อย ]
 (ยอดชั่วโมง + อาหาร + เติมเงิน)    (พนักงานพิมพ์ใน LINE: /pay 350 ค่าน้ำแข็ง)
              │                                │
              └───────────────┬────────────────┘
                              ▼
                ╔════════════════════════════╗
                ║   n8n DAILY CRON ENGINE    ║
                ║      (ทำงานทุก 23:59 น.)    ║
                ╚════════════════════════════╝
                              │
                              ▼
                [ สรุปรายงานการเงินเข้า LINE ผู้บริหาร ]
                • ยอดขายรวม (Gross Revenue)
                • ค่าชั่วโมงเกมมิ่ง / ยอดสมาชิก
                • ค่าอาหาร & เครื่องดื่ม
                • หัก: รายจ่ายประจำวัน
                • = กำไรสุทธิประจำวัน (Daily Net Profit)
```

### คำสั่งด่วนสำหรับพนักงานบันทึกรายจ่ายผ่าน LINE:
พนักงานหรือผู้จัดการร้านสามารถพิมพ์คำสั่งในกลุ่ม LINE พนักงาน เพื่อลงบัญชีรายจ่ายได้ทันที เช่น:
- `/pay 450 ค่าล้างแอร์โซน VIP`
- `/pay 1,200 สั่งไก่ป๊อปและเฟรนช์ฟรายส์เข้าร้าน`
ระบบ n8n จะตัดยอดและรวมในงบดุลประจำวันให้อัตโนมัติ

## 4. ระบบติดตาม Leads และสถานะลูกค้า (Lead Pipeline)

เมื่อมีลูกค้าติดต่อขอ **เช่าจัดแข่งอีสปอร์ต** หรือ **สนใจลงทุนเปิดร้านแฟรนไชส์** ข้อมูลจะถูกจัดเก็บบันทึกอัตโนมัติลงฐานข้อมูลและแสดงในหน้า **Admin CMS / Google Sheets**:

| ขั้นตอน (Stage) | ความหมาย | สิ่งที่ระบบทำอัตโนมัติ |
| :--- | :--- | :--- |
| **1. Lead ใหม่ (New Lead)** | ลูกค้ากรอกฟอร์มหรือทักแชทสนใจเปิดร้าน | n8n ส่งแจ้งเตือนด่วนเข้า LINE กลุ่มฝ่ายขายทันที |
| **2. ติดต่อแล้ว (Contacted)** | แอดมินโทรสอบถามข้อมูลและขนาดพื้นที่ | บันทึกประวัติการโทรและโน้ตความต้องการ |
| **3. ส่งใบเสนอราคา (Quotation Sent)** | ส่งแปลน 3D และงบ Size S/M/L ให้ลูกค้าพิจารณา | ระบบติดตามสถานะอัตโนมัติ (แจ้งเตือนโทรตามใน 3 วัน) |
| **4. ปิดการขายสำเร็จ (Closed Won)** | เซ็นสัญญาและเริ่มดำเนินงานก่อสร้าง | ส่งข้อมูลเข้าสู่ระบบช่างเทคนิคและวางแผนผังร้าน |

## 5. ระบบติดตามอุปกรณ์และทรัพย์สินในร้าน (Hardware Asset Tracking)

สำหรับศูนย์อีสปอร์ตขนาด 70 - 120 เครื่อง การเช็กสถานะอุปกรณ์มีความสำคัญอย่างยิ่ง:
- **รหัสเครื่อง (Station ID):** ตั้งแต่ `PC-01` ถึง `PC-120`, `VIP-01` ถึง `VIP-06`, `STAGE-01` ถึง `STAGE-10`
- **การตรวจจับผ่านระบบ Diskless:**
  - ตรวจสอบสถานะการเชื่อมต่อ LAN (Online / Offline / Gaming)
  - นับชั่วโมงการทำงาน (Operating Hours) ของการ์ดจอ RTX 40 Series และจอ 360Hz
- **บันทึกประวัติการส่งเคลม (RMA / Warranty Tracker):**
  - บันทึก Serial Number (S/N) ของการ์ดจอ, จอภาพ BenQ, และหูฟัง
  - เมื่ออุปกรณ์เสีย พนักงานสามารถคลิกเปิดเคสส่งเคลมประกัน (Synnex, Ingram, Ascenti) ในระบบ CMS ได้ทันที พร้อมระบบแจ้งเตือนเมื่อของเคลมส่งกลับมาถึงร้าน

## 6. Docker Compose ส่วนขยาย (รวม Chatwoot + n8n + Web + DB)

เพิ่ม Service ของ **Chatwoot** ในไฟล์ `docker-compose.yml` บนเซิร์ฟเวอร์:

```yaml
  # -------------------------------------------------------------
  # Chatwoot - Unified Omnichannel Customer Support Inbox
  # -------------------------------------------------------------
  chatwoot:
    image: chatwoot/chatwoot:latest
    container_name: gspeed_chatwoot
    restart: always
    ports:
      - "3001:3000"
    environment:
      - FRONTEND_URL=https://inbox.gspeedarena.com
      - NODE_ENV=production
      - RAILS_ENV=production
      - SECRET_KEY_BASE=gspeed_chatwoot_secure_token_2026
      - DATABASE_URL=postgres://postgres:password@postgres:5432/chatwoot_production
      - REDIS_URL=redis://redis:6379
      - ACTIVE_STORAGE_SERVICE=local
    depends_on:
      - postgres
      - redis
```

## สรุปภาพความสำเร็จ
ด้วยแผนสถาปัตยกรรมนี้ คุณจะได้:
1. **หน้าจอเดียวจบ (Single Pane of Glass)**: แอดมินและผู้บริหารเปิดหน้าจอเดียว ดูแชทได้ทั้ง LINE, Facebook, และเว็บ
2. **AI ตอบไว 24 ชม.**: ลูกค้าไม่รอนาน ข้อมูลร้านแม่นยำ
3. **แอดมินแทรกตอบได้ตลอดเวลา**: พร้อมชื่อและรูปโปรไฟล์แอดมิน รู้ว่าใครตอบอะไร ยอดเยี่ยมเรื่องความโปร่งใส
4. **บัญชีและการเงินอัตโนมัติ**: สรุปยอดรายรับ/รายจ่ายประจำวันส่งตรงถึงมือถือผู้บริหารทุกเที่ยงคืน
5. **Leads ไม่สูญหาย**: ลูกค้าทักเรื่องเปิดร้านหรือจัดแข่ง ระบบล็อกข้อมูลและติดตามผลทันที
